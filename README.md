# 💰 Expense Tracker – Python Desktop Application

## 📌 Project Overview

The **Expense Tracker** is a Python-based desktop application designed to help users record and manage their daily expenses. It calculates the total number of expenses and generates an expense summary, making it easier to monitor personal spending.

This project demonstrates Python programming, GUI development, and basic expense management.

## 🎯 Project Objectives

- Record daily expenses.
- Manage expense information.
- Calculate the total number of expenses.
- Generate an expense summary.
- Display the final expense amount.

## ✨ Features

- **Expense Management:** Add and track expenses.
- **Expense Summary:** View the number of recorded expenses.
- **Total Calculation:** Automatically calculate the total expense amount.
- **User Interface:** Interactive desktop application.
- **Currency Format:** Display expense amounts in Indian Rupees (₹).

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Sitha-mounika/Expense---Tracker.git
```

### 2. Navigate to the project folder

```bash
cd Expense---Tracker
```

### 3. Run the application

```bash
python src/expense_tracker.py
```

## 💻 Application Output

The application generates an expense summary containing:

- Number of expenses recorded.
- Final total expense amount.

Example:

```text
---------------------------
Expense Summary
---------------------------
Number of expenses: 2
Final Total: ₹2550.00
---------------------------
```
